# RankPulse 回测摘要

最后更新：2026-08-15

本文档保留历史研究结果，方便追溯策略来源。

注意：

- 历史回测使用本地 1H K 线 cache 重建 24H 涨幅榜。
- live/testnet 当前默认使用 Binance `/fapi/v1/ticker/24hr` 排名。
- 因为排名来源不同，回测结果不能直接等同于 live 结果。
- 当前代码已经接入 live/testnet 执行模块，因此旧文档里的“research only”不再代表当前工程状态。

## 1. 历史回测设置

- 市场：Binance USD-M Futures USDT 永续
- 方向：只做多
- 信号时间：北京时间 00:00 / 08:00
- 排名来源：本地 1H K 线重建 24H 涨幅榜
- 手续费：买入 0.1%，卖出 0.1%
- 滑点：0
- 单笔保证金：100U
- 默认持有：6D
- 提前退出：4H extreme weak exit、12H weak exit
- 同 symbol 持仓期间不重复开仓

## 4. 历史结论

历史样本中：

- 20%-40% 是主要收益来源。
- Rank3 在 20%-40% 中贡献较大，但杠杆风险也最高。
- 40%-60% 较弱，因此当前只保留 Rank2 且使用较低杠杆。
- 60%-80% 直接过滤。
- `>=80%` 直接过滤。

## 5. FR3/YR1 研究结论

## 6. 重要限制

历史回测没有完整模拟：

- 盘口深度
- 实际滑点
- 资金费率
- 市价单冲击
- Binance 精确强平模型
- 网络延迟
- API 错误
- 部分成交

因此，回测只说明历史样本中的策略表现，不保证未来收益。
